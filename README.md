# Space Explorer

A full-stack NASA exploration dashboard built with Next.js.

## Features

- Browse NASA's Astronomy Picture of the Day
- Search the NASA Image and Video Library
- Save images to Favorites
- Delete saved favorites
- View near-Earth object data
- View recent favorites on the dashboard
- Store favorites using Prisma and SQLite
- Responsive design

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Prisma
- SQLite
- NASA Open APIs
- Recharts

## Pages

- Dashboard
- Astronomy Picture of the Day
- NASA Image Library
- Favorites
